# Place publique

Un petit script affichant en temps réel des images de webcam et utilisant l'algorithme YOLO (You Only Look Once) de Ultralytics pour détecter les éléments de l'image. L'algorithme de segmentation YOLO-seg est utilisé pour colorer les pixels des objets détectés.


## Description des codes: 

***url***  L'url du flux webcam

***model*** Le modèle YOLO que l'on choisit d'utiliser
